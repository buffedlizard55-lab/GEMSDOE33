# Why the owner-reported `h27-4-r1-solo-d2-8` scored 0.2708 — and the route past it

**Evidence boundary.** The 0.2708 value and preceding campaign scores are owner-reported manual
results, not organizer receipts in this repository. The underlying score-inversion analysis is from the
GEMSDOE28 campaign record. The public leader is a separate official, dated observation: `nchuzhoy` 0.3262
on the leaderboard checked 2026-10-03 local. No score is available here for the current C2 file.

## 1. Metric and marginal-value rule

For the distance-weighted Tversky score, the current metric description is
`DTI = TP / (TP + 0.2·FP + 0.8·FN)`, with a 300 m triangular spatial kernel. Using `FN = |G| − TP`
reduces this to `TP / (0.2·TP + 0.2·FP + 0.8·|G|)`. Under the metric's definitions, adding prediction
mass raises DTI only when its marginal credited truth mass per marginal false-positive mass exceeds
`0.2·DTI / (1 − 0.2·DTI)`.

| Reference DTI | Break-even credit per FP-mass unit |
|---:|---:|
| 0.2477 (owner-reported) | ≈0.052 |
| 0.2708 (owner-reported baseline) | ≈0.0573 |
| 0.3195 (historical leaderboard observation) | ≈0.0683 |
| 0.3262 (official snapshot, 2026-10-03) | ≈0.0698 |

This rule is an algebraic marginal condition, not a prediction of achievable score. At roughly 40,000
emitted dots, false-positive mass is consequential; however, the weighted TP/FP contributions are spatial
and must not be equated mechanically with raw dot counts.

## 2. Owner-reported winning lineage

| **h27-4-r1-solo on d=2.8** | **40,199** | **0.2708** | **blind one-pixel catalogue-flank prune** |

These values and the mechanism labels come from the owner's prior campaign record, not verified organizer
receipts. The reported gain has three plausible contributors:

1. **Dotting beats solid lines.** For a one-dimensional fault crest, dots at spacing `s ≤ 3 px` can retain
   useful triangular-kernel credit along the crest while emitting less prediction mass than a continuous
   line. The owner-reported d=2.8 result retained much of the d=1.5 score with fewer dots; it should not be
   read as a universal packing optimum.
2. **The target is off-catalogue.** The challenge describes hidden expert labels as faults absent from
   the existing public catalogue. Predictions on known catalogue lines can therefore spend mass without
   matching that target; proximity and mask semantics still require care.
3. **Blind flank pruning.** The prior analysis reports that a one-pixel catalogue-flank prune raised the
   score by +0.0108. Its “pure denominator mass” interpretation is an inference from the owner's held-out
   analyses, not proof that every removed pixel was false. Those historical masks and the full inversion
   evidence are not duplicated in this repository.

## 3. Current target and limits of the old budget calculation

The current official leaderboard snapshot is 0.3262, making the arithmetic score gap from the
owner-reported 0.2708 baseline **0.0554**. A previous back-of-envelope pixel-budget calculation targeted
0.3195 and used an estimated hidden-truth credit fraction from an earlier campaign analysis. That number
is stale against the newer leaderboard observation. The original inversion inputs and their uncertainty
are not fully present in this checkout, so this file deliberately does **not** update the old estimate of
required dots or credited truth mass. Recompute from the source score inversion and its assumptions
before quoting one. The marginal threshold at 0.3262 is shown above; it is not a target-score forecast.
