Manual upload steps

  1. Download the current candidate from the download page. It is a single GeoTIFF, not a zip or a bundle.
  2. Open the official DOE GEMS Prize Challenge page and navigate to its submission form. Sign in yourself if the site asks; this repository does not log in for you.
  3. Select the downloaded .tif as the submission file and review the portal's current validation message before continuing.
  4. If the portal provides an optional description/note field, paste the candidate note below. It describes local proxy evidence and explicitly says the file is unscored.
  5. Review the file name and candidate, then submit manually. Save the organizer's actual receipt/result and update the ledger only after it exists.

Artifact format and audit

The official submission-format instructions specify a single-layer float32 GeoTIFF on the competition grid (UTM Zone 11N, EPSG:32611, 100 m) with predictions in [0,1]. They describe null/NaN outside the prediction bounds. The repository's fail-closed audit compares the candidate against the supplied sample-grid template and also enforces a conservative local policy of finite values everywhere and zeros in template cells outside the survey footprint. That project policy is deliberately distinguished from the organizer's published format rules.

Owner-observed portal message: “Predicted values must be in range [0, 1]” while using an older NaN-outside file (IR-PORTAL-01). NaNs are a plausible cause; no organizer support ruling confirming the cause is available. The current artifacts avoid NaNs and pass the local audit, but a local pass is not a guarantee of portal acceptance.

Slot and result policy

  • Do not use a weekly submission slot unless the candidate passes the documented frozen P1/P2 gate (positive P1 mean, a strict majority of P1 folds positive, and P2 ΔDTI ≥ −0.001) and the exact output file passes the format audit.
  • Log the returned result as owner-reported until an organizer receipt is archived. Do not infer a score from proxy performance.
  • The official challenge description says the expert panel reviews submissions and the Final Prize Round uses expanded labels to evaluate the selected submission. Preserve a geologically defensible provenance record for every proposed trace.
  • This codebase, its feed generator, and its CI workflow do not log in to, upload to, scrape, or poll DrivenData. The leaderboard shown on the results page is a manually checked dated snapshot.
