Exact submission steps (official rules, verified)

  1. Download the TIF from the download page (single-band GeoTIFF; a .zip containing the single GeoTIFF is also accepted by the portal).
  2. Open the competition submission form: drivendata.org → GEMS Prize Challenge → Submit (requires your DrivenData login — this repo never logs in for you).
  3. File to submit: choose the downloaded .tif.
  4. Note (optional): paste the short comment shipped with the file. For the current candidate:
    33GEMSDOE C2 stepover relay | P1 dDTI +0.00043 3/4 folds, P2 +0.00028 vs scored 0.2708 base | id eb6bcf02361f | proxy-gated, unscored
  5. Submit. The portal validates: single-band GeoTIFF, CRS/shape/geotransform matching the sample submission, and predicted values in [0, 1] across the whole array.

Why earlier files were rejected — and why ours pass

Owner-reported portal error: “Predicted values must be in range [0, 1]” (irregularity IR-PORTAL-01). Cause: the upload form validates the entire array and rejects NaN — files that stored NaN outside the survey footprint failed even though every in-footprint value was valid.

Every GEMSDOE33 artifact is therefore written finite everywhere: values in [0, 1], zero (never NaN) outside the footprint, float32, EPSG:32611, 100 m, identical shape/geotransform/bounds to the official sample submission. Each file ships with its format audit JSON (evidence/format_check_*.json) proving these checks passed byte-for-byte.

Slot policy (read before using a weekly slot)

  • Submissions are limited per week; never spend a slot on a file that has not beaten the current holdout best on the frozen P1/P2 gate (evidence/holdout33.json).
  • Record the returned live score in registry/score_ledger.json (owner-reported) so the 24-submission inversion stays calibrated.
  • Before the deadline, select the single submission that will score in BOTH rounds — the Final Prize Round re-scores the same file against the expert-expanded label set, so favour geologically defensible, independently corroborated traces.
