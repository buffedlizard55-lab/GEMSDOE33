Mission

Win the DOE GEMS Prize Challenge: map geological faults in the GeoDAWN region (northwestern Great Basin) that are missing from the public USGS/INGENIOUS catalogue, because those are exactly the faults the expert panel labelled as ground truth. Current standing: owner-reported campaign best 0.2708 (h27-4-r1-solo) vs public leader 0.3195 (“DARD”).

Why 0.2708 won, and the plan past it

  • Metric: distance-weighted Tversky index, α=0.2 / β=0.8, 300 m triangular kernel — false positives are cheap but unbounded; false negatives are capped by the hidden truth |G| ≈ 12,226 px.
  • The 0.2708 file = 40,199 sparse dots from the H19-5 scarp/geophysics ridge ensemble, Poisson-thinned to 2.8 px spacing, with the blind 1-px catalogue-flank prune (H27-4). Dots near known catalogue faults can never earn credit because the scoring truth is off-catalogue by construction.
  • Reaching 0.3195 requires ~+24% credited truth mass at the same dot budget, or ~half the dots at equal credit. Packing tricks are exhausted (marginal return 0.031 credit/dot < 0.055 break-even). The only route is new, high-specificity off-catalogue evidence.

This session's strategy: bounded analog-field transfer + stepover relays

1. Borrow ground truth from better-mapped analog fields, with the transfer bounded. Dixie Valley, Desert Peak and Brady's have decades of industry-drilling-verified fault mapping. Ben-David et al. (2010, DOI 10.1007/s10994-009-5152-4) bound target-domain error by source-domain error plus the measured divergence between feature distributions (classifier-two-sample-test / dA-distance). Where divergence is small, analog geometries become a genuinely independent validation set never touched by the GeoDAWN catalogue. Sources verified obtainable: GDR #207 GIS_Faults.zip (Dixie Valley), NBMG OF 03-27 (Desert Peak–Brady's), GDR #1288 labelled grids. Bytes require an unrestricted machine (sandbox egress is GitHub-only).

2. Stepover relay bridges (implemented, proxy-gated, shipped above). Both Desert Peak and Brady's geothermal fields are hosted in fault step-overs (Faulds et al., OSTI 1110517): relay ramps between fault tips concentrate dense unmapped strands. We emit sparse bridge dots between distinct-FID tip pairs (300–2500 m approach, ≤30° strike) gated by an isostatic-gravity horizontal-gradient edge — mechanistically distinct from the failed T-v2 rule, which filled same-polyline compiler gaps.

Validation discipline

  • P1: catalogue-hidden 4-fold spatial block holdout (LOSFO-style, 600 m system grouping) — paired ΔDTI vs the scored control.
  • P2: SGMC off-catalogue faults ≥300 m from the catalogue — an independent compilation as truth substitute.
  • Gate: P1 mean ΔDTI > 0, majority folds positive, P2 not worse than −0.001. C2 passed; C3 re-pack refuted.
  • No weekly slot is ever spent on a file that has not beaten the current holdout best. Proxies are labelled proxies — never scores.
