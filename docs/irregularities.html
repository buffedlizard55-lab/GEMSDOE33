IR-33-NODATA-01highmitigated for packaged reference fileThe template mask has 5,167,373 finite cells. In the owner-mirrored training raster, 3,061 of those cells carry the float32 nodata sentinel in each of 18 bands; band 6 (tc) has 12 additional sentinel cells (3,073 total). These counts were measured by reading the raw float32 band bytes and intersecting with the template footprint. The earlier 1,521-cell claim was incorrect because it compared whole-raster valid counts from grids with different masks.

Evidence: Reproducible per-band counts in evidence/input_grid_audit.json, generated by scripts/audit_inputs.py from the 17 hash-verified owner-mirror inputs.

Consequence: Any model writing raw nodata sentinels as probabilities can trigger the portal's [0,1] error. The reference TIFF is re-written from a source raster that already contains only 0/1/NaN and is validated on disk. This does not prove it will pass the organizer's portal.
