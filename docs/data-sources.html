Conditions for any future Ben-David-style claim

  1. Named, audited source and target domains with source label provenance.
  2. Shared feature layers and common sampling support; account for spatial autocorrelation.
  3. Spatial overlap/deduplication and a justified hypothesis class.
  4. Source error, valid HΔH divergence estimate, finite-sample complexity term, and joint-label error λ. A discriminator AUC alone is not the bound.
  5. Independent spatial confirmation; analog catalogue lines are not automatically independent truth.
