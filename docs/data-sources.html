Analog data and transfer limits

No independent dense analog truth was found. The reviewed GEMSDOE24 labels.tif and existing_faults.tif are byte-identical. Repository searches did not locate independent Dixie Valley, Brady or Desert Peak field-verified labels. A33-L1 therefore uses named-field windows and the visible mapped catalogue for a constrained transfer experiment; it is not true leave-one-field-out validation against independent truth.

The shared feature stack contains official-band-derived structural layers, restored from 17 SHA-256-pinned owner-mirror inputs. All 17 were restored and grid-audited, but an owner mirror is not proof of organizer provenance. The sample submission exactly reproduces catalogue values on its finite footprint and is used only for shape, transform, CRS and footprint.

What A33-L1 did—and did not—test

  • Tested: whether target-CDF adaptation and equal field weighting make named-window structural appearance improve a fold-safe target regional expert.
  • Controlled: whole fault components, 15-pixel fold buffer, fold-visible catalogue sampling, pixel-exact masking, feature-alone canaries, matched dot budgets.
  • Did not establish: independent source error, dense source-label quality, a Ben-David target-error bound, or performance on private hidden faults.
  • Result: adapted fusion beat raw pooled analog transfer but lost to the regional expert; negative.

External hypotheses and availability

BRIDGE / DOE GDR context: public metadata was reviewed in earlier work, but no independently verified dense named-field label payload was pinned here. Geometry, label policy and overlap must be audited before use.
USGS seismicity and geothermal context: official/free source concepts were identified, but this environment's outbound allowlist did not permit payload verification. They remain blocked, not “viable” inputs.

Conditions for a valid transfer-bound claim

  1. Independent, audited source labels and a target evaluation set not derived from the same catalogue.
  2. Common feature support, spatial deduplication and explicit survey/acquisition confound controls.
  3. Source error, a justified divergence estimator, finite-sample term and joint-label error assumptions—not a classifier AUC alone.
  4. Predeclared field holdout and off-catalogue confirmation before any competition slot.
