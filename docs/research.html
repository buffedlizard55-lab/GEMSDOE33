Ben-David et al. (2010), Theorem 2 requires source error plus one half of an empirical HΔH divergence, a defensible finite-sample/class-complexity term, and the joint-label error lambda. A generic two-sample AUC is not by itself that bound. Paper · implementation notes.

Blocking gates

  1. Obtain and inspect the official BRIDGE vector archive; verify coordinate reference system, field IDs, confidence/verification attributes, and license conditions.
  2. Define source and target as named, non-overlapping field polygons before examining target benchmark outcomes; do not substitute record-density quantiles.
  3. Declare identical target hypothesis class, label policy, feature schema, spatial resolution, mask, and physically interpretable covariate transformations in both fields.
  4. Use field/system-level spatial blocks for train, domain-discriminator validation, and evaluation; prevent neighboring pixels or duplicate site records crossing partitions.
  5. Specify how source risk, the HΔH class/divergence, effective independent sample size and confidence intervals will be estimated.
  6. Estimate or conservatively bound lambda with an independent shared-label audit; do not set lambda to zero by assumption.
  7. Obtain a target-relevant, spatially blocked holdout and compare transferred candidates at matched emission budget before any submission-slot decision.
